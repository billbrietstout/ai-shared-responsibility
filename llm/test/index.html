About this tool

The corpus is built from /export/framework.json (definitions plus concept labels). Scoring uses BM25 over tokenized chunks. A low confidence score or empty concept hits for a term that should exist signals a chunking gap or a missing semantic link worth fixing at the source. Append &format=json to any query URL to get the JSON response only.
