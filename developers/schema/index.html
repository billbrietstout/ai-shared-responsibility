SRF Schema Viewer

Machine-readable accountability ontologies, evidence manifests, and RACI schemas for the CoSAI AI SRF. Designed for ingestion by GRC platforms, AI gateways, and observability systems.

Coming in v2.0 These schemas are planned for the v2.0 release. The accountability ontology and evidence manifest formats are in active design — open an issue on GitHub to influence the schema before it ships.

What's planned

The v2.0 framework development plan includes a canonical schema repository covering three artifact types:

Accountability ontology — A graph-structured model of the five SRF layers, eight personas, and four operating models. Expressed in JSON-LD and YAML. Enables tooling to reason about responsibility assignments without parsing prose.

Evidence manifests — Structured templates defining what evidence satisfies each accountability assignment by layer and operating model. OSCAL-compatible JSON format for integration with existing GRC workflows.

RACI templates — Pre-populated responsibility matrices per operating model (AI-SaaS, AI-PaaS, Agent-PaaS, IaaS), exportable as machine-readable JSON and as human-readable PDF.

Timeline

Phase 1 (0–3 months from v2.0 launch): schema design, initial governance ontology, and a public GitHub repository for community contribution.

Contribute

The schema design is open for discussion now. If you are working on GRC tooling, AI gateway integrations, or observability systems that need to consume governance data programmatically, open an issue on the GitHub repository to influence the schema design.
