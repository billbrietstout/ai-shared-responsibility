What preview means

This map is a preview. Risk-to-obligation links are in the data. Each link is indirect: it runs through a control that addresses the risk and cites the obligation. The link does not mean the legal text names the risk.

Looking for security requirements? A separate catalog is not in the data yet.

No security-requirement catalog

A security-requirement catalog is not in the data yet. This explorer uses the word obligation for the records that exist. Choose a risk or a control to see those obligations in the chain. This list is not titled security requirements.
