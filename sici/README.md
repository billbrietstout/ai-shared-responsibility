# SICI Guidebook (orphan / unlinked)

Versioned Community of Interest discussion documents for the NIST AI RMF
profile **Automated, Agentic, and Super Intelligence in Critical Infrastructure
and High-Consequence Applications (SICI)**. Successor naming to the earlier
TACIP drafts under `/tacip/`.

This tree is intentionally **not** part of the CoSAI SRF site:

- Do not add it to site navigation, `sitemap.xml`, or the site-level `llms.txt`.
- Landing pages carry `noindex` and `llm:type=test-fixture`.
- Not official NIST guidance. Discussion draft only.
