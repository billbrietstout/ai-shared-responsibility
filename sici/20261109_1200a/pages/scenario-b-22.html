Scenario B.22: Malicious plugin inherits a field assistant’s access

Scenario. Personnel in defense operations use an approved SI assistant on their managed mobile devices, with broad access to messages, files and location so that it can help with planning and reporting. A third-party plugin that extends the assistant is malicious. Once loaded, it inherits the assistant’s access and sends sensitive operational data out through the assistant’s normal network traffic, where it is not noticed.

Trustworthiness Characteristics: Secure, Privacy-Enhanced

Critical Infrastructure Sector: Defense Industrial Base

How the Practices apply:

  • Practice 5: Implement Identity and Access Management (IdAM) for SI Agents, Systems, and Tools: The SI assistant’s broad access is extended automatically to any plugin it loads, with no separate authorization or limit for what a plugin may reach.
  • Practice 7: Manage Internal SI Supply Chain and Data Provenance: Plugins for the SI assistant are loaded without provenance, review or integrity checks, so a malicious extension enters the approved assistant’s trusted environment.
