Scenario B.23: Over-privileged yard-coordination agent forces a full disconnection

Scenario. A maritime terminal operator uses an SI agent to coordinate yard operations, including gate scheduling, crane assignments and truck appointments. Because scoping its access proved difficult, it was given administrator-equivalent privileges across terminal systems. Attackers compromise the agent through its internet-facing interface. The operator cannot separate the agent’s legitimate actions from the intruder’s, so it disconnects the whole network to contain the intrusion, halting land-side cargo operations across several ports.

Trustworthiness Characteristics: Secure, Resilient

Critical Infrastructure Sector: Transportation Systems

How the Practices apply:

  • Practice 5: Implement Identity and Access Management (IdAM) for SI Agents, Systems, and Tools: The SI agent holds administrator-equivalent privileges because scoping them was difficult, and its actions are not attributable separately from anyone else using that access, so containing a compromise means disconnecting everything.
