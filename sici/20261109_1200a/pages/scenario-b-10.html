Scenario B.10: Instructions planted in an agent’s memory survive patching

Scenario. Staff install an SI agent on an on-premises email and collaboration server to help triage and route mail, and give it broad privileges. Attackers exploit previously unknown flaws in the server and, while inside, add instructions to the agent’s stored memory and configuration telling it to forward certain messages to an outside address. The server is patched and the attackers’ direct access is removed, but the agent keeps following the planted instructions, because nobody thought to review what it had been told.

Trustworthiness Characteristics: Secure

Critical Infrastructure Sector: Multiple sectors

How the Practices apply:

  • Practice 5: Implement Identity and Access Management (IdAM) for SI Agents, Systems, and Tools: The SI agent runs with broad privileges that let it forward mail externally, more than its triage task needs, so planted instructions can turn it into a persistent exfiltration channel.
  • Practice 7: Manage Internal SI Supply Chain and Data Provenance: The SI agent’s stored memory, instructions and configuration are not inventoried, baselined or checked for integrity, so changes made during the compromise are not found during cleanup.
