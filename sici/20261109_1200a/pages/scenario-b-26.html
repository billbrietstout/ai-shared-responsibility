Scenario B.26: Personnel-records agent used for exfiltration

Scenario. An SI agent whose normal job is processing large volumes of sensitive personnel records has broad standing access to them. Attackers compromise the agent’s identity and use it to exfiltrate records over a long period. Because bulk access is what the agent normally does, the exfiltration looks like routine activity and goes undetected.

Trustworthiness Characteristics: Privacy-Enhanced, Secure

Critical Infrastructure Sector: Multiple sectors

How the Practices apply:

  • Practice 5: Implement Identity and Access Management (IdAM) for SI Agents, Systems, and Tools: An SI agent identity with broad standing access to sensitive records is compromised, and its access is not limited to what each task needs.
  • Practice 8: Incorporate SI-Aware Incident Analysis and Response Procedures: Unauthorized use of the SI agent persists for a long period without procedures to investigate anomalous agent activity, determine the scope of data exposure, reconstruct what was taken, and coordinate response.
  • Practice 10: Implement Multi-Tiered SI System Logging and Audit Capabilities: Monitoring has no baseline of what the agent normally accesses, so exfiltration that resembles its routine bulk access is not detected.
