Scenario B.25: Dam gate-scheduling agent instructed in natural language

Scenario. Operators of a small flood-control dam instruct an SI agent in plain language, through a remote interface, to schedule gate releases, and the agent holds control privileges over the dam’s SCADA system. The interface is reachable from outside and weakly protected. Attackers find it and tell the agent to fully open a gate “for a maintenance test”, and the agent, treating it as an operator request, complies.

Trustworthiness Characteristics: Safe, Secure

Critical Infrastructure Sector: Dams

How the Practices apply:

  • Practice 3: Define Risks, Policies, and Oversight for Automated, Agentic, and SI Behavior: The SI agent can carry out high-consequence physical actions on a plain-language instruction, without confirmation, authorization boundaries or limits on how far it may open a gate, so a plausible request is enough.
  • Practice 5: Implement Identity and Access Management (IdAM) for SI Agents, Systems, and Tools: The remote interface to the SI agent is exposed and weakly protected, and the agent does not verify who is instructing it, so anyone who reaches the interface can act with its control privileges.
